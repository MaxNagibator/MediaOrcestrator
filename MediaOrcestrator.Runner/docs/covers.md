# Генератор обложек

Автоматически делает обложки для группы видео по общему шаблону. Полезно, когда нужно поставить на 20 серий подряд
одинаковые превью с разными номерами — не руками в фотошопе, а одним кликом.

Используется в окне **Обновление превью** (правый клик по нескольким медиа → «Обновить превью»). Там появляется режим *
*«Из шаблона»** рядом с «Из источника» и «Из файла».

## Как пользоваться

1. В таблице медиа выделите нужные видео (Ctrl+клик или Shift+клик)
2. Правый клик → «Обновить превью»
3. Включите режим **«Из шаблона»**
4. Нажмите **«Настроить…»** — откроется редактор шаблона
5. Выберите картинку-шаблон, расставьте слои, нажмите **OK**
6. Выберите целевые площадки в списке «Куда загрузить»
7. **«Применить»** — на каждое видео генерируется своя обложка и загружается на выбранные площадки

Сгенерированные обложки живут в `temp_path/{guid}/cover_{номер}.png` и удаляются после загрузки.

## Шаблон обложки

**Файл шаблона** — обычная картинка (PNG / JPG / WEBP), поверх которой рисуются слои с текстом. Разрешение любое — слои
масштабируются от высоты картинки, обложка корректно отрисуется и на 1280×720, и на 1920×1080.

**Слои** — произвольное количество текстовых надписей. Каждый слой имеет свои координаты, шрифт, размер, цвет заливки,
обводку. Рисуются по порядку сверху вниз по списку — верхние элементы в ListBox рисуются первыми, нижние — поверх.

### Редактирование слоя

Выделите слой в списке «Слои» — снизу активируется группа «Текущий слой»:

- **Текст** — строка с возможным плейсхолдером `{number}`. Примеры: `{number}`, `Серия {number}`, `EP.{number}`, `ФИНАЛ`
- **Шрифт** — любой установленный в системе (перечисляются Skia-именами, чтобы шрифт точно резолвился рендером)
- **Начертание** — `Обычный` / `Жирный` / `Курсив` / `Жирный курсив`
- **Размер** — в процентах от высоты картинки (25% — крупный, 10% — мелкий)
- **Обводка** — толщина в процентах от высоты; 0% = без обводки
- **Заливка** / **Цвет обводки** — кнопки открывают стандартный диалог цвета (только RGB, без альфы)
- **Прозрачность зал.** / **Прозрачность обв.** — 0..255 (255 — непрозрачно, 0 — полностью прозрачно). Меняется отдельно
  от диалога цвета: ColorDialog Windows альфу не предлагает

### Добавить слой / Удалить

Кнопки справа от списка. Новый слой создаётся с дефолтными параметрами (белый текст, чёрная обводка, центр по X, сверху
по Y). Удалить последний оставшийся слой нельзя.

### Позиционирование

**Клик левой кнопкой мыши по превью** задаёт позицию выбранного слоя. Координаты хранятся как доли от размера картинки (
0.5 × 0.5 = центр), поэтому работают одинаково для любого разрешения шаблона.

## Нумерация

Определяет, какое число подставится вместо `{number}` в каждом слое для каждой обложки.

### Последовательно

Простой режим — каждой обложке присваивается номер `Начальный № + позиция в выборке`. Если выбрано 5 видео и начальный
номер 3, то обложки получат номера 3, 4, 5, 6, 7. Порядок соответствует порядку медиа в гриде.

### Из названия (regex)

Полезно, когда у видео в базе уже есть номер в заголовке — например «Бэкпекинг по Казахстану #12». Генератор вытаскивает
номер регуляркой из `Media.Title` и подставляет в шаблон.

**Поле Regex** — регулярное выражение, первая группа захвата используется как номер. Если групп нет — используется всё
совпадение. Если совпадения нет или в заголовке нет цифры — фолбэк на `Начальный № + позиция`.

**Примеры регулярок:**

- `#?(\d+)` — универсальный, берёт первое число, опционально после `#`
- `[Сс]ерия\s+(\d+)` — только после слова «Серия»
- `EP\.?\s*(\d+)` — только после «EP» / «EP.»
- `\((\d+)\)` — число в скобках, например «Финал (13)»

**Если регулярка невалидная или зависает** (таймаут 100 мс) — в логи пишется warning, используется фолбэк. Пакет не
падает.

## Профили

Редактор умеет сохранять настройки целиком (файл шаблона, режим нумерации, regex, все слои, цвета, позиции) в
именованный профиль. Хранится в `{папка с settings.txt}/templates/covers/{имя}.json`.

Рядом с JSON автоматически кладётся **резервная копия картинки-шаблона** — `{имя}.png` (или другое расширение,
соответствующее оригиналу). JSON хранит абсолютный путь к выбранному вами файлу как источник правды; копия —
страховка на случай, когда оригинал переехал или был удалён. При загрузке профиля: если абсолютный путь
доступен — используется он; если нет — подменяется на копию из папки профиля. Удаление профиля чистит и копию.

### Сохранить как

Кнопка **«Сохранить как…»** в группе «Профиль» — вводите имя, сохраняется. Если профиль с таким именем уже есть —
спросит подтверждение перезаписи.

### Загрузить

Выберите профиль в комбобоксе, нажмите **«Загрузить»** — форма переоформляется целиком под загруженные настройки.
Несохранённые текущие изменения теряются.

### Удалить

Кнопка **«Удалить»** — спросит подтверждение, удалит JSON из папки профилей.

### Быстрое переключение

В окне «Обновление превью» рядом с кнопкой «Настроить…» есть свой комбобокс профилей — можно переключиться между
готовыми профилями одним движением, не заходя в редактор.

### OK поверх именованного профиля

Если в заголовке окна виден текущий профиль (например, `Шаблон обложки — Сезон1`), нажатие **OK** также перезаписывает
этот профиль — отдельной кнопки «Сохранить» нет, OK = «сохранить и применить». Если нужно не трогать исходный
профиль, а получить разовую правку — используйте «Сохранить как…» под новым именем (после этого заголовок переключится
на новое имя, и OK сохранит уже туда), либо отмените изменения через «Отмена».

## Примеры

### Нумерованные серии одного сезона

- **Шаблон:** фон с лого шоу
- **Слой 1:** `{number}` в правом нижнем углу, крупно, белый с чёрной обводкой
- **Нумерация:** Последовательно, начальный № = 1

### Финальная серия отдельно

- **Шаблон:** тот же фон
- **Слой 1:** `ФИНАЛ` по центру, крупно
- Сохранить как профиль «Финал», переключиться перед применением

### Парсинг номеров из готовых названий

Медиа в базе: `Марафон #01`, `Марафон #02`, … `Марафон #15`:

- **Слой 1:** `Серия {number}`
- **Нумерация:** Из названия, regex `#(\d+)`
- Каждая обложка получит свой номер, даже если в выборке пропущены серии

### Две надписи на одной обложке

- **Слой 1:** `Серия {number}` в верхнем левом углу
- **Слой 2:** `МЕДИА ОРКЕСТРАТОР` внизу, жёлтый, крупнее

## Нюансы и грабли

- **Порядок в выборке важен.** В режиме «Последовательно» номер зависит от позиции видео в таблице. Если отсортировать
  грид иначе — номера поедут. Проверяйте порядок перед нажатием «Применить».
- **`{number}` — единственный плейсхолдер.** Подстановка `{title}` / `{date}` пока не поддерживается.
- **Прозрачность задаётся отдельным полем**, не через диалог цвета — стандартный Windows ColorDialog альфу не
  предлагает.
- **Шрифт по умолчанию — Impact**, если он установлен. Иначе Arial Black, иначе — первый в списке.
- **Файл шаблона хранится по абсолютному пути**, но рядом с профилем лежит резервная копия — если оригинал переехал,
  загрузка профиля бесшовно подхватит копию из папки `templates/covers/`. Если редактор не видит ни оригинал, ни копию —
  выберите файл заново.
- **Шаблон меньше 1280×720** — редактор покажет предупреждение. Сама обложка сгенерируется в исходном разрешении, без
  апскейла; платформы могут отказать или показать мыло.
